# Bar Tent — QR-меню с заказом на столик

Гость сканирует QR на столике → открывается меню на телефоне (испанский / английский / украинский) →
добавляет позиции → «Отправить заказ» → заказ появляется на экране бара с номером столика.
Оплаты нет (пока): гость платит как обычно.

## Запуск (на этом компьютере)
```
cd C:\Users\user\Documents\Meta-Bitrix\bar-tent
node server.js
```
- Меню гостя: http://localhost:3000/?t=12 (`t` — номер столика; можно без него, тогда гость вводит номер сам).
- Экран бара: http://localhost:3000/bar — PIN из `data/config.json` (сейчас `1234`).
- QR-коды для печати: http://localhost:3000/qr (число столиков: `/qr?n=30`). Печать Ctrl+P.

В баре экран открывают на планшете/компьютере один раз, он сам обновляется (живое соединение) и пищит на новый заказ.
Заказы хранятся в `data/orders.json` (на экране бара видны за последние 24 часа).

## Файлы
- `data/menu.json` — всё меню: разделы, позиции, цены, названия на трёх языках, фото. Правится в блокноте,
  сервер перечитывает его сам (без перезапуска). `"check": true` — цену надо уточнить (см. ниже).
- `data/config.json` — название, порт, число столиков, PIN бара, `publicUrl` (адрес сайта для QR-кодов,
  если сайт стоит за доменом).
- `public/img/` — фото позиций: `<id>.jpg` 1200 px и `<id>-s.jpg` 480 px; `logo.svg` — векторный логотип.
- `tools/photos.mjs` — пересборка фото из макета Xara (квадрат на чёрном + кривая яркости как в печатном меню).

## Что надо уточнить (цен в макете не было)
Помечено `"check": true` в `menu.json`: Coca-Cola и другая газировка (поставлено 2,5 €), вода (1,5 €),
соки (2,5 €), безалкогольные мохито и пина колада (6,0 €, как лимонады), пивная башня (на тенте 16,2 €,
в А5-меню 19,0 €). Коктейли: на тенте 8,5 €, в А5-меню 9,0 € — поставлено 8,5 €.

## Чтобы работало с телефонов гостей
Нужен сервер в интернете с Node.js (любой VPS за ~5 €/мес, или Railway / Render / Fly.io — бесплатные
тарифы подойдут для начала) и домен, например `menu.bartent.es`. Шаги: скопировать папку, `npm install`,
`node server.js` (лучше через pm2), в `config.json` указать `publicUrl`, напечатать QR с `/qr`.
Обязательно сменить PIN бара.
